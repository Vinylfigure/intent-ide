### `getDocGraph`'s inflight-dedupe capability mismatch -- fix delivered, PR #131 MERGED (confirmed merged as of the memory-bank catch-up session, 2026-08-30)
Closes issue #127 (filed 2026-08-27 as a work-loop idle-evaluation proposal, named as a known pre-existing debt in the Cascade v2 roadmap close-out but never fixed until now — carried in §3/§4 as the "Inflight-dedupe race" line since the Wave D1+D2 finale).
- [x] **The bug:** `getDocGraph` (`src/lib/graphrag/docGraph.ts`) deduped concurrent builds for the same document content-hash via an `inflight` map keyed only on the hash. `scheduleDocGraphRebuild` calls it on every debounced edit with `skipLlm`/`skipEmbeddings`/`skipGraphiti` all true (deliberate deterministic-only background build — document text must never leave the machine as a side effect of typing). - [x] **The fix — option (b) from #127's own stated acceptable approaches:** `inflight` entries now carry the capability set (`{llm, embeddings, graphiti}`) they'll deliver. - [x] **Two rounds of pre-push adversarial review, BOTH NO-MERGE with a blocking, empirically-reproduced finding, both fixed with regression tests before the PR was opened:**

**Corrections to previously overstated claims:**
- **Cascade lacks the direct-edit trigger.** `proposeCascadeEdits` is invoked only from `attachCascadeEdits` (`resolver.ts`) — i.e., only when an AI resolution proposes an edit. Directly typing a change into the document never triggers a cascade (EditorShell `docChanged` → save + deterministic-only rebuild). * **The LLM edge pass (`link_blocks`) is not part of the new idle-enrichment timer** (`feat/reading-quality`, `scheduleDocGraphEnrichment`) — only embeddings run on the 12s idle timer; whole-doc `link_blocks` on a local 8B model would take minutes. LLM edges still only ever arrive via a resolved cascade edit.
